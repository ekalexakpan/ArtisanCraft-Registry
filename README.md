# ArtisanCraft Registry

A blockchain-based platform for authenticating and tracking handmade crafts, providing provenance and quality verification for artisan creations.

## Features

- Craft registration and authentication
- Quality grade verification
- Artisan provenance tracking
- Availability status management
- Category-based organization

## Smart Contract Functions

### Public Functions
- `register-craft`: Register a new handmade craft
- `mark-as-sold`: Update craft availability status

### Read-Only Functions
- `get-craft-details`: Retrieve craft information
- `get-artisan-address`: Get artisan's address

## Supported Categories
- Pottery, Woodworking, Textiles, Metalwork, Glassblowing, Jewelry

## Quality Grades
- Master, Expert, Skilled, Apprentice, Novice
